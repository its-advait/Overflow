# Threat model

**Assets:** treasury USDC on Base Sepolia, each order's escrowed USDC and seller bond, the agents' budgets, and the books. **Assumption:** any agent can be prompt-injected and any seller can cheat. The defense is that a valid signature is never enough to move money: only `OverflowTreasury` (`settle()` / `reserve()`) and `OverflowEscrow` move USDC, and USDC asks the treasury (ERC-1271) before every transfer that names the treasury as payer. Trust boundaries: [architecture.md](architecture.md#trust-boundaries).

**Proof column key.** Contract tests are Foundry test functions under `contracts/test/` (last run: 20 suites, 196 passed, 0 failed, 1 skipped; docs/PROGRESS.md "end-to-end purchase flow"). `fork-test` means `contracts/test/fork/UsdcGate.t.sol` against live Base Sepolia USDC (7 passed; docs/PROGRESS.md "hardening pass"). `proof #n` is a case in docs/proof/results.md, run on an **anvil fork** of Base Sepolia: its tx hashes are local to the fork and **not on Basescan**. Vitest tests are named by file and title. No refusal has landed on Basescan yet, because the live runs were blocked on funding ([limitations.md](limitations.md)), so the live column is TODO everywhere.

## Out of scope

- Recourse proves delivery against commitments and signed promises, not that the data is true.
- Policies and budgets are public onchain.
- Agent keys sit in server secrets for the demo.
- The contracts are unaudited and testnet-only.

See [limitations.md](limitations.md) for the full list.
